# Fullstack_Application
Created with CodeSandbox

This is a project I created following the offical React Tic Tac Toe tutorial for Fullstack at Brown.

1) The project produces a playable game of Tic Tac Toe. It alternates between player X and player O's turns, declares the winner (or if it was a tie), and does not allow the game to continue after it is finished. 
2) Download the code and run it on your platform of your choice.
3) I added a draw message that displays if there is a draw. 
4) One challenged I faced was adding the draw message. Because I didn't have a tutorial as a guide if I got stuck I had to reread the code multiple times to ensure I understood what was going on and to find the best place to put the draw message. However, through that experience, I felt that I understood the code much more than reading explanations and then copying the code. 
5) Credit for all the code, both ideas and implementations, belong to the offical React Tic Tac Toe tutorial except for the draw message code which is found on lines 30-32.
